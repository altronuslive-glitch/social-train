# План реализации улучшенной системы анализа и генерации контента

## Анализ текущего состояния

### Что уже есть:
1. **Парсеры**: Telegram (работает), VK (базовая версия)
2. **Analyzer**: анализирует текст через DeepSeek, изображения через Claude
3. **Агенты**: SMM Agent, Image Agent, Art Director Agent
4. **Pipeline**: генерирует 20 постов через цепочку агентов
5. **API эндпоинт**: `/api/analyze` - полный цикл анализ → генерация

### Текущие ограничения:
1. Claude не работает (невалидный ключ) → анализ изображений не работает
2. DeepSeek пока не используется для анализа изображений
3. Нет отдельных агентов для анализа текста и изображений (сейчас это один analyzer)
4. Нет формирования "карточки бренда"
5. Нет генерации изображений (только промпты)
6. Нет UI для работы с системой

## Требования из задачи

### 1. Обновить DeepSeek для поддержки изображений
DeepSeek теперь поддерживает мультимодальность - нужно добавить эту функциональность

### 2. Два отдельных агента анализа
**Агент анализа текста:**
- Анализирует 30 постов
- Формирует документ с tone of voice, характеристиками, примерами
- Выделяет особенности стиля общения

**Агент анализа изображений:**
- Анализирует визуальный контент
- Определяет типы (фото, иллюстрации, инфографика)
- Категории изображений
- Форматы и композиция
- Методы применения визуала

### 3. Карточка бренда
Объединяет результаты двух агентов:
- Типы постов
- Соответствующие изображения для каждого типа
- Визуальные паттерны
- Tone of voice
- Рекомендации по контенту

### 4. Арт-директор
Формирует общее настроение бренда на основе карточки (уже есть, но нужно адаптировать)

### 5. Workflow (пайплайн)
1. Вставка ссылки на канал
2. Парсинг 30 постов
3. Параллельный анализ:
   - Агент текста → документ tone of voice
   - Агент изображений → документ визуального стиля
4. Формирование карточки бренда (объединение результатов)
5. Арт-директор → общее настроение бренда
6. Генерация 20 тем для постов
7. Предложение тем пользователю
8. Генерация постов по выбранным темам
9. Генерация изображений через Grok API

### 6. Простой веб-интерфейс
HTML страница для удобной работы с системой

### API эндпоинты

**1. POST /api/analyze/channel**
```json
{
  "channel": "cvetidnya",
  "postsCount": 30
}
```
Возвращает: карточку бренда + 20 предложенных тем

**2. POST /api/generate/posts**
```json
{
  "brandCard": {...},
  "selectedTopics": [1, 3, 5, 7, ...]
}
```
Возвращает: сгенерированные тексты постов

**3. POST /api/generate/images**
```json
{
  "posts": [...],
  "grokApiKey": "xai-..."
}
```
Возвращает: URL сгенерированных изображений

## Детальный план реализации

### Этап 1: Обновление DeepSeek для мультимодальности
**Файл:** `src/services/deepseek.js`

Добавить функцию `callDeepSeekVision()`:
- Поддержка массива content с типами 'text' и 'image_url'
- Аналогично GPT-4o формату
- Использовать модель с поддержкой vision (если есть у DeepSeek)

### Этап 2: Создание агента анализа текста
**Файл:** `src/services/analyzers/textAnalyzer.js`

Функция `analyzeTextContent(posts)`:
- Принимает 30 постов
- Возвращает детальный документ:
  ```js
  {
    toneOfVoice: {
      summary: "...",
      characteristics: [...],
      examples: [...],  // примеры фраз из постов
      language: "...",
      emotionality: "...",
      humor: "...",
      appeals: "...",
      forbiddenTone: "..."
    },
    contentPatterns: {
      avgPostLength: "...",
      structure: "...",
      usesEmoji: true/false,
      usesHashtags: true/false,
      bestPerformingType: "..."
    },
    topics: [
      { name: "...", frequency: "...", examples: [...] }
    ],
    audience: {
      portrait: "...",
      painPoints: [...],
      desires: [...]
    }
  }
  ```

### Этап 3: Создание агента анализа изображений
**Файл:** `src/services/analyzers/imageAnalyzer.js`

Функция `analyzeImageContent(posts)`:
- Фильтрует посты с изображениями
- Анализирует через DeepSeek Vision (или fallback на текстовое описание если vision недоступен)
- Возвращает:
  ```js
  {
    hasImages: true/false,
    imageTypes: {
      photos: 40%,
      illustrations: 30%,
      infographics: 20%,
      collages: 10%
    },
    categories: ["продукты", "люди", "природа", ...],
    formats: {
      square: 50%,
      vertical: 30%,
      horizontal: 20%
    },
    visualStyle: {
      colorPalette: ["#...", "#...", ...],
      mood: "...",
      composition: "...",
      patterns: [...]
    },
    usageMethods: {
      withText: true/false,
      overlays: true/false,
      filters: "..."
    },
    examples: [
      { imageUrl: "...", description: "...", category: "..." }
    ]
  }
  ```

### Этап 4: Создание строителя карточки бренда
**Файл:** `src/services/analyzers/brandCardBuilder.js`

Функция `buildBrandCard(textAnalysis, imageAnalysis)`:
- Объединяет результаты двух агентов
- Формирует карточку бренда:
  ```js
  {
    brand: {
      niche: "...",
      description: "...",
      uniqueness: "..."
    },
    toneOfVoice: { ...from textAnalyzer },
    visualIdentity: { ...from imageAnalyzer },
    contentTypes: [
      {
        type: "полезный совет",
        textCharacteristics: "...",
        visualRecommendation: "...",
        frequency: "...",
        examples: [...]
      },
      // ... другие типы
    ],
    artDirectorBrief: "Общее настроение и рекомендации"
  }
  ```

### Этап 5: Обновление арт-директора
**Файл:** `src/services/agents/artDirectorAgent.js`

Добавить функцию `createArtDirectorBrief(brandCard)`:
- Анализирует карточку бренда целиком
- Формирует единое видение бренда
- Создает руководство для генерации контента

### Этап 6: Генерация тем для постов
**Файл:** `src/services/topicGenerator.js` (новый)

Функция `generateTopics(brandCard, count = 20)`:
- На основе карточки бренда генерирует 20 тем
- Каждая тема:
  ```js
  {
    id: 1,
    title: "...",
    description: "...",
    contentType: "...",
    goal: "...",
    visualSuggestion: "..."
  }
  ```

### Этап 7: Обновление pipeline
**Файл:** `src/services/pipeline.js`

Новая функция `runFullPipeline(channel, selectedTopicIds)`:
1. Парсинг постов
2. Параллельный анализ (текст + изображения)
3. Формирование карточки бренда
4. Генерация 20 тем
5. Если переданы selectedTopicIds:
   - Генерация постов только по выбранным темам
   - Для каждого поста: SMM Agent → Image Agent → Art Director

### Этап 8: Интеграция Grok API
**Файл:** `src/services/grok.js` (новый)

Функция `generateImage(prompt, apiKey)`:
- Отправка запроса к Grok API для генерации изображений
- Возврат URL изображения
- Обработка ошибок

### Этап 9: Обновление API эндпоинтов
**Файл:** `src/routes/analyze.js`

Изменить текущий эндпоинт:
- POST `/api/analyze/channel` - возвращает карточку бренда + темы
- POST `/api/analyze/generate-posts` - генерирует посты по выбранным темам
- POST `/api/analyze/generate-images` - генерирует изображения через Grok

### Этап 10: Веб-интерфейс
**Файл:** `src/public/index.html`

Простой одностраничный интерфейс:
1. **Форма ввода**
   - Поле для ссылки на канал
   - Кнопка "Анализировать"

2. **Результаты анализа**
   - Карточка бренда (свернутая/развернутая)
   - Список из 20 предложенных тем с чекбоксами
   - Кнопка "Сгенерировать посты по выбранным темам"

3. **Сгенерированные посты**
   - Список постов с текстами и промптами
   - Кнопка "Сгенерировать изображения"
   - Поле для Grok API ключа

4. **Финальный результат**
   - Посты с изображениями
   - Кнопка "Скачать все"

## Технические детали

### DeepSeek Vision поддержка
Нужно уточнить, поддерживает ли DeepSeek изображения:
- Если да - использовать мультимодальный API
- Если нет - использовать текстовые описания изображений (извлекать metadata, alt-text, etc.)

### Grok API
Формат запроса (предположительно схож с OpenAI):
```js
{
  model: "grok-vision" // или другая модель
  prompt: "...",
  size: "1024x1024",
  // другие параметры
}
```

### Хранение данных
Для простоты - в памяти (переменные).
Для production - можно добавить Redis/MongoDB.
