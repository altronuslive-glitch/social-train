# Social Train 🚂

AI-сервис для планирования контента в социальных сетях. Принимает описание темы/бизнеса, генерирует план постов на месяц через Claude SDK, подбирает хэштеги и промпты для изображений.

## Стек

- **Node.js** + **Express** — HTTP-сервер
- **Claude SDK** (`@anthropic-ai/sdk`) — генерация контент-плана
- **Railway** — хостинг (деплой через GitHub)

## Запуск локально

```bash
# 1. Скопируй .env.example в .env и заполни ключ
cp .env.example .env

# 2. Установи зависимости
npm install

# 3. Запусти сервер
npm run dev
```

## API

### `POST /api/content/plan`

Генерирует план на 20 постов (4 недели × 5 постов).

**Тело запроса:**
```json
{
  "topic": "Фитнес-студия для взрослых",
  "audience": "Женщины 30-45 лет",
  "tone": "мотивирующий",
  "month": "сентябрь 2026"
}
```

**Ответ:**
```json
{
  "success": true,
  "plan": {
    "posts": [
      {
        "week": 1,
        "day": "Понедельник",
        "topic": "...",
        "caption": "...",
        "hashtags": ["#фитнес", "..."],
        "imagePrompt": "..."
      }
    ]
  }
}
```

### `GET /health`

Проверка работоспособности сервиса (используется Railway).
